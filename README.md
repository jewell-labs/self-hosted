# self-hosted

Every top-level directory is one isolated package. `core` is the minimum needed to add a plugin and to set a package up from an existing install.

`core/PRINCIPLES.md` is the rule every package follows. `core/README.md` is the operational guide. Each package has its own `README.md` and `AGENTS.md`.

This root has two files: `README.md` and `AGENTS.md`.
